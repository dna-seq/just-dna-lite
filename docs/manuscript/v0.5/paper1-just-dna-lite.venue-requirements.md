# What the venues on this ladder ask for: BMC Bioinformatics, Cell Reports Methods, Genome Biology, Bioinformatics (Original Paper), PLOS Computational Biology (Software), NAR Genomics and Bioinformatics, Genomics, Proteomics & Bioinformatics and bioRxiv

Each requirement is listed with the venues that ask for it; "every venue" means all of them. A venue missing from an item may simply not have been researched for it (see the last section), which is not the same as having no rule.

## Adapt now: one version serves every venue

- Sections to add (one a single venue requires costs the others little):
  - [ ] Data availability (Bioinformatics (Original Paper))
  - [ ] Availability and Implementation (in the abstract) (Bioinformatics (Original Paper))
- Rules the editors check on arrival, to check against the draft:
  - [ ] ML papers validated by leave-one-out are editorially rejected (Bioinformatics (Original Paper))
  - [ ] New methods compared with state of the art (Bioinformatics (Original Paper))
  - [ ] Pre-screen returns papers of less significance (Bioinformatics (Original Paper))
  - [ ] All data on which the conclusions are based publicly available in stable public repositories (Supporting Data) (Bioinformatics (Original Paper))
  - [ ] No narrative reviews (bioRxiv)
  - [ ] No announcements of tools or services without data (bioRxiv)
  - [ ] No hypotheses without new data (bioRxiv)
  - [ ] No editorials (bioRxiv)
  - [ ] Letters (bioRxiv)
  - [ ] Opinion pieces (bioRxiv)
  - [ ] White papers or policy statements (bioRxiv)

## Choose per venue: the venues disagree

These wait until the venue is chosen, or follow the first rung of the ladder.

- Length of the body: the limits differ (Cell Reports Methods, 7000; Bioinformatics (Original Paper), 5000; PLOS Computational Biology (Software), 3500; Genomics, Proteomics & Bioinformatics, 6000 words). Writing to the shortest, 3500 words, fits all of them; whether that cut is worth making before the choice is your decision.
- Length of the abstract: the limits differ (BMC Bioinformatics, 350; Genome Biology, 100; Bioinformatics (Original Paper), 150; PLOS Computational Biology (Software), 300 words). Writing to the shortest, 100 words, fits all of them; whether that cut is worth making before the choice is your decision.
- Abstract headings differ: BMC Bioinformatics: Background, Results, Conclusions; Genome Biology: no headings (unstructured); Bioinformatics (Original Paper): Motivation, Results, Availability and Implementation, Contact, Supplementary Information.
- Rules that only some venues state. Those that cost the others nothing (alt text, dataset citations) can be adopted now; a section order or a reference style waits for the choice:
  - Sections Background, Implementation, Results, Discussion, Conclusions, then Availability and requirements (BMC Bioinformatics)
  - The sections of an Original Paper in this order: Title page, Structured Abstract, Introduction, System and methods, Algorithm, Implementation, Discussion, References (Bioinformatics (Original Paper))
  - Alt text for every image and figure of the main article, in the manuscript file directly under its legend (Bioinformatics (Original Paper))
  - Supplementary Data submitted for review apart from the manuscript, with all its text, figures and tables in a single file, and referred to in the main text (Bioinformatics (Original Paper))
  - The funding in a section titled Funding, first in the Acknowledgements, as a sentence that begins "This work was supported by", with the full agency names and the grant numbers in square brackets (Bioinformatics (Original Paper))
  - Every public dataset cited in the reference list with its identifier, the citation beginning with the tag [dataset] (Bioinformatics (Original Paper))
  - A cover letter that explains why the paper suits the journal, and why the manuscript departs from the instructions wherever it does (Bioinformatics (Original Paper))
  - A declaration, at the first submission, of any author or contributor who is the journal's Editor-in-Chief, an editor or an editorial board member (Bioinformatics (Original Paper))
  - Sections Introduction, Design and Implementation, Results, Availability and Future Directions; the title names the software (PLOS Computational Biology (Software))
  - A cover letter that explains how the Software criteria are met (PLOS Computational Biology (Software))
- Not needed until after the first review:
  - The reference style, Oxford SCIMED (Bioinformatics (Original Paper))

## At the end, once the code, data and results are final

Done earlier, these have to be done twice.

- Software and availability:
  - [ ] Availability and requirements block with archived DOI (BMC Bioinformatics and Genome Biology)
  - [ ] Open-source licence recommended but not required (BMC Bioinformatics)
  - [ ] Public repository with OSI licence (Genome Biology)
  - [ ] Source at a stable URL at submission (Bioinformatics (Original Paper))
  - [ ] Archived version (Zenodo, Software Heritage or Figshare) URL in the abstract (Bioinformatics (Original Paper))
  - [ ] Test data (Bioinformatics (Original Paper) and PLOS Computational Biology (Software))
  - [ ] Install and run documentation (Bioinformatics (Original Paper))
  - [ ] Instructions to reproduce each figure (Bioinformatics (Original Paper))
  - [ ] OSI-compliant source code (PLOS Computational Biology (Software))
  - [ ] Documentation (PLOS Computational Biology (Software))
- Where the AI-use statement goes (one statement, placed everywhere a venue asks):
  - [ ] AI declaration (BMC Bioinformatics and Genome Biology)
  - [ ] Methods (BMC Bioinformatics, Genome Biology and PLOS Computational Biology (Software))
  - [ ] Titled declaration after Declaration of interests (published) (Cell Reports Methods)
  - [ ] Methods or STAR Methods when AI is part of the research design or methods (Cell Reports Methods)
  - [ ] Cover letter (Bioinformatics (Original Paper), NAR Genomics and Bioinformatics and Genomics, Proteomics & Bioinformatics)
  - [ ] Methods or Acknowledgements (Bioinformatics (Original Paper))
  - [ ] Supplementary materials (Bioinformatics (Original Paper))
  - [ ] Acknowledgements or figure legend (PLOS Computational Biology (Software))
  - [ ] Acknowledgements (NAR Genomics and Bioinformatics and Genomics, Proteomics & Bioinformatics)
  - [ ] Methods if integral (NAR Genomics and Bioinformatics and Genomics, Proteomics & Bioinformatics)
  - [ ] In the manuscript (bioRxiv)
  - [ ] As for other computational methods (bioRxiv)
- What the AI-use statement states:
  - [ ] Use (BMC Bioinformatics and Genome Biology)
  - [ ] Author accountability (BMC Bioinformatics and Genome Biology)
  - [ ] AI-assisted content labelled (BMC Bioinformatics and Genome Biology)
  - [ ] Tool (Cell Reports Methods, Bioinformatics (Original Paper), NAR Genomics and Bioinformatics and Genomics, Proteomics & Bioinformatics)
  - [ ] Reason (Cell Reports Methods)
  - [ ] Model or tool + version + developer or manufacturer for research use and data visualizations (Cell Reports Methods)
  - [ ] Version (Bioinformatics (Original Paper), NAR Genomics and Bioinformatics and Genomics, Proteomics & Bioinformatics)
  - [ ] How used (Bioinformatics (Original Paper), PLOS Computational Biology (Software), NAR Genomics and Bioinformatics and Genomics, Proteomics & Bioinformatics)
  - [ ] Which parts (Bioinformatics (Original Paper))
  - [ ] Author oversight (Bioinformatics (Original Paper), NAR Genomics and Bioinformatics and Genomics, Proteomics & Bioinformatics)
  - [ ] Tools (PLOS Computational Biology (Software))
  - [ ] What it affected (PLOS Computational Biology (Software))
  - [ ] How outputs were validated (PLOS Computational Biology (Software))
  - [ ] Dates (recommended) (NAR Genomics and Bioinformatics and Genomics, Proteomics & Bioinformatics)
  - [ ] Sections (recommended) (NAR Genomics and Bioinformatics and Genomics, Proteomics & Bioinformatics)
  - [ ] Use of generative AI tools (bioRxiv)
- Extra work about AI:
  - [ ] Supplementary documentation of any LLM help that produced part of the content (Bioinformatics (Original Paper))
  - [ ] AI-written code must be disclosed (PLOS Computational Biology (Software))
  - [ ] Update the disclosure at every revision (NAR Genomics and Bioinformatics and Genomics, Proteomics & Bioinformatics)

## AI writing rules on the list

- BMC Bioinformatics: AI help is allowed if declared, except that the results and discussion are reserved for the authors.
- Cell Reports Methods: AI help is allowed if declared, and language polish needs no declaration.
- Genome Biology: AI help is allowed if declared, except that the results and discussion are reserved for the authors.
- Bioinformatics (Original Paper): the journal asks authors not to have AI draft text; correction aids are allowed.
- PLOS Computational Biology (Software): AI help is allowed if declared, and language polish needs no declaration.
- NAR Genomics and Bioinformatics: AI help is allowed if declared, and language polish needs no declaration.
- Genomics, Proteomics & Bioinformatics: AI help is allowed if declared, and language polish needs no declaration.
- bioRxiv: AI help is allowed if declared, and language polish needs no declaration.

The strictest is Bioinformatics (Original Paper)'s: the journal asks authors not to have AI draft text; correction aids are allowed. A manuscript written and declared to that rule keeps every venue on the list open; whether to write to it is your decision.
