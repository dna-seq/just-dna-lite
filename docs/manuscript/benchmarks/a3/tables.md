# A3 benchmark tables (generated)

Generated by `scripts/make_tables.py` from the committed files in this directory. Do not edit by hand; rerun the script.

Wall time is `cli_wall_s`: the whole command, from start to report written, for both generations (Generation II: `uv run annotate`; Generation I: `docker run … oakvar run`). Warm: the normalized parquet is reused, so the VCF is not read. Full: a fresh instance and output directory with warm OS caches, normalization included, the like-for-like counterpart of an OakVar run. Cold: as full, with the OS page cache dropped right before.
