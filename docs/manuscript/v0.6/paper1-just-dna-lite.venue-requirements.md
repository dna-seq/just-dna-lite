# What the venues on this ladder ask for: iScience, Frontiers in Bioinformatics, JAMIA Open, Cell Reports Methods, Genomics, PLOS Computational Biology (Software), NAR Genomics and Bioinformatics, Cell Genomics, bioRxiv and arXiv

Each requirement is listed with the venues that ask for it; "every venue" means all of them. A venue missing from an item may simply not have been researched for it (see the last section), which is not the same as having no rule.

## Adapt now: one version serves every venue

- Rules the editors check on arrival, to check against the draft:
  - [ ] No narrative reviews (bioRxiv)
  - [ ] No announcements of tools or services without data (bioRxiv)
  - [ ] No hypotheses without new data (bioRxiv)
  - [ ] No editorials (bioRxiv)
  - [ ] Letters (bioRxiv)
  - [ ] Opinion pieces (bioRxiv)
  - [ ] White papers or policy statements (bioRxiv)
  - [ ] At most 2 submissions per calendar month and 3 active per submitter; rejected ones count (arXiv)
  - [ ] CS review and position papers need a peer-reviewed version (journal ref and DOI) (arXiv)
  - [ ] A full English version is required (arXiv)
  - [ ] New submitters need an endorsement (institutional email alone no longer suffices) (arXiv)

## Choose per venue: the venues disagree

These wait until the venue is chosen, or follow the ladder's first choice.

- Length of the body: recorded limits are Frontiers in Bioinformatics, 12000; Cell Reports Methods, 7000; PLOS Computational Biology (Software), 3500; Cell Genomics, 8000 words; other venues' limits are unknown. Keep this as a venue-specific choice until those rules are checked; no shared cap is established.
- Length of the abstract: recorded limits are Genomics, 250; PLOS Computational Biology (Software), 300 words; other venues' limits are unknown. Keep this as a venue-specific choice until those rules are checked; no shared cap is established.
- Rules that only some venues state; a section order, a format or a reference style waits for the choice:
  - Sections Introduction, Design and Implementation, Results, Availability and Future Directions; the title names the software (PLOS Computational Biology (Software))
  - A cover letter that explains how the Software criteria are met (PLOS Computational Biology (Software))

## At the end, once the code, data and results are final

Done earlier, these have to be done twice.

- Software and availability:
  - [ ] OSI-compliant source code (PLOS Computational Biology (Software))
  - [ ] Documentation (PLOS Computational Biology (Software))
  - [ ] Test data (PLOS Computational Biology (Software))
- Where the AI-use statement goes (one statement, placed everywhere a venue asks):
  - [ ] Titled declaration after Declaration of interests (published) (iScience, Cell Reports Methods and Cell Genomics)
  - [ ] Methods or STAR Methods when AI is part of the research design or methods (iScience, Cell Reports Methods and Cell Genomics)
  - [ ] Acknowledgments (Frontiers in Bioinformatics)
  - [ ] Methods if applicable (Frontiers in Bioinformatics)
  - [ ] Cover letter (JAMIA Open and NAR Genomics and Bioinformatics)
  - [ ] Acknowledgements (JAMIA Open and NAR Genomics and Bioinformatics)
  - [ ] Methods if integral (JAMIA Open and NAR Genomics and Bioinformatics)
  - [ ] Separate declaration section immediately before the references (published) (Genomics)
  - [ ] Methods (AI in the research process or to write or edit code) (Genomics)
  - [ ] Methods (PLOS Computational Biology (Software))
  - [ ] Acknowledgements or figure legend (PLOS Computational Biology (Software))
  - [ ] In the manuscript (bioRxiv)
  - [ ] As for other computational methods (bioRxiv)
  - [ ] In the work (arXiv)
  - [ ] As for other methodology (arXiv)
- What the AI-use statement states:
  - [ ] Tool (iScience, JAMIA Open, Cell Reports Methods, Genomics, NAR Genomics and Bioinformatics and Cell Genomics)
  - [ ] Reason (iScience, Cell Reports Methods and Cell Genomics)
  - [ ] Model or tool + version + developer or manufacturer for research use and data visualizations (iScience, Cell Reports Methods and Cell Genomics)
  - [ ] Name (Frontiers in Bioinformatics)
  - [ ] Version (Frontiers in Bioinformatics, JAMIA Open and NAR Genomics and Bioinformatics)
  - [ ] Model (Frontiers in Bioinformatics and Genomics)
  - [ ] Source (Frontiers in Bioinformatics)
  - [ ] How used (JAMIA Open, PLOS Computational Biology (Software) and NAR Genomics and Bioinformatics)
  - [ ] Author oversight (JAMIA Open, Genomics and NAR Genomics and Bioinformatics)
  - [ ] Dates (recommended) (JAMIA Open and NAR Genomics and Bioinformatics)
  - [ ] Sections (recommended) (JAMIA Open and NAR Genomics and Bioinformatics)
  - [ ] Purpose (Genomics)
  - [ ] Extent (Genomics)
  - [ ] Tools (PLOS Computational Biology (Software))
  - [ ] What it affected (PLOS Computational Biology (Software))
  - [ ] How outputs were validated (PLOS Computational Biology (Software))
  - [ ] Use of generative AI tools (bioRxiv)
  - [ ] Significant use of text-to-text generative AI (arXiv)
- Extra work about AI:
  - [ ] Update the disclosure at every revision (JAMIA Open and NAR Genomics and Bioinformatics)
  - [ ] AI-written or AI-edited code declared in detail in Methods (Genomics)
  - [ ] AI-written code must be disclosed (PLOS Computational Biology (Software))

## AI writing rules on the list

- iScience: AI help is allowed if declared; only explicitly recorded exemptions apply.
- Frontiers in Bioinformatics: AI help is allowed, but every use must be declared, even language polish.
- JAMIA Open: AI help is allowed if declared; only explicitly recorded exemptions apply.
- Cell Reports Methods: AI help is allowed if declared; only explicitly recorded exemptions apply.
- Genomics: AI help is allowed if declared; only explicitly recorded exemptions apply.
- PLOS Computational Biology (Software): AI help is allowed if declared; only explicitly recorded exemptions apply.
- NAR Genomics and Bioinformatics: AI help is allowed if declared; only explicitly recorded exemptions apply.
- Cell Genomics: AI help is allowed if declared; only explicitly recorded exemptions apply.
- bioRxiv: AI help is allowed if declared; only explicitly recorded exemptions apply.
- arXiv: AI help is allowed if declared; only explicitly recorded exemptions apply.

The strictest rule on the list is Frontiers in Bioinformatics's: AI help is allowed, but every use must be declared, even language polish. For the AI use you described, it means: allowed, but every use must be declared.
